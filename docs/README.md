# Typst learning guide

This folder contains short guides to help you **learn Typst** and **edit this resume** with confidence. Use them as a reference when changing `resume.typ` or customizing the layout.

## Guide index

| Doc | What you'll learn |
|-----|-------------------|
| [01 – Typst basics](01-typst-basics.md) | Syntax: markup vs code, headings, text, variables, comments. |
| [02 – Editing this resume](02-editing-this-resume.md) | Where to change name, experience, education, skills; how arrays and dictionaries work. |
| [03 – Styling and layout](03-styling-and-layout.md) | Colors, `#set` / `#show`, blocks, grids, lines—enough to tweak the look. |

**Suggested path:** Read **01** for syntax, then **02** when editing content. Use **03** when you want to change colors, spacing, or layout.

## Quick reference (for this resume)

- **Compile to PDF:** `typst compile resume.typ resume.pdf`
- **Watch mode:** `typst watch resume.typ resume.pdf` (recompile on save)
- **Main file:** `../resume.typ` — all content and styling live there
